# Flutter Course DS

Educational repository created to help junior developers learn how to build apps with Flutter through a clear study path and practical examples.

## What you will learn

- How Flutter projects are organized
- How widgets are used to build user interfaces
- How to manage state in simple applications
- How to navigate between screens
- How to consume and display data in an app

## Who this repository is for

This repository is aimed at developers who are starting with Flutter and want a simple reference for the main concepts involved in building mobile apps.

## Recommended learning path

1. Install Flutter and configure your development environment
2. Create your first project with `flutter create`
3. Learn the difference between `StatelessWidget` and `StatefulWidget`
4. Build layouts with common widgets such as `Scaffold`, `Column`, `Row`, `ListView`, and `Container`
5. Practice navigation, forms, and state updates
6. Evolve your app with API integration and project organization

## Getting started with Flutter

Before using the examples in this repository, make sure you have:

- Flutter installed: https://docs.flutter.dev/get-started/install
- An editor configured for Flutter, such as VS Code or Android Studio
- A device emulator or physical device for testing

Useful commands:

```bash
flutter doctor
flutter create my_first_app
cd my_first_app
flutter run
```
